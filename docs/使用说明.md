# PolyU Canvas Localized · 原型使用说明

适用于 Apple Silicon Mac，macOS 13 或更新版本。

## 安装

打开 DMG，将 PolyU Canvas Localized 拖到 Applications，再从 Applications 启动。此原型使用 ad-hoc 签名，尚未 Apple 公证；首次打开可能需要在系统「隐私与安全」里允许。

## 开始使用

1. 选择已有课程资料文件夹，或创建默认资料库。已有文件不会被移动或删除。
2. 点击「连接 Canvas」，在学校登录窗口完成账号登录和 MFA。回到工作台后点击「同步 Canvas」。
3. 在资料库打开文件，可以查看本地读取的文字和页码，也可以用系统应用打开原文件。
4. 没有 AI 密钥时，先用「本地规则提取日期」或手动添加任务。
5. 要使用自己的 AI，在设置填写基础地址、模型 ID 和 API 密钥，再选择文件并确认发送正文。
6. 到「待确认」核对标题、日期、时间、原文和页码，确认后加入任务和日历。
7. 点击「导出日历」，保存 ICS，再使用自己的日历应用导入。

## 你需要知道

- 文件分类先改标签，不自动移动或改名原文件。
- Week 7、日期不明确、来源冲突等需要你补充核对，不会自动猜测。
- 无日期的任务保留在清单里，不会导出到日历。
- 有具体时间的 DDL 标记截止时刻，不表示考试时长。
- App 打开期间每小时检查一次 Canvas，关闭后停止。同步不会覆盖你修改过的下载文件；新版另存。
- 在本地删除的下载文件不自动恢复；设置中的恢复按钮可以重新下载。
- 退出 Canvas 保留资料和安排，清除账号会话和文档读取缓存。
- 演示课程是合成资料，可以在侧边栏载入和单独移除。
- 聊天产品订阅不一定包含 API；请使用服务商提供的 API 凭据。

Apple 日历/提醒事项自动写入、手机双向同步和真实 syllabus 的 AI 识别效果将在后续版本验证。
